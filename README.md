# 🍔 FoodieFly – Online Food Ordering System

## 📌 Project Overview
FoodieFly is a full-stack web application that allows users to browse restaurants, explore menus, and place food orders online. It is designed to simplify the food ordering process and improve user experience.

---

## 🚀 Features
- User Registration & Login System
- Browse Restaurants & Menus
- Add to Cart Functionality
- Place Orders
- Admin Panel for Order Management
- Database Integration (MySQL)

---

## 🛠️ Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Python (Flask)
- Database: MySQL
